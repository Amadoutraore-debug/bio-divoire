# GreenBasket

Site vitrine d'une épicerie bio en ligne (une page, en français) : fruits, légumes et produits frais livrés à domicile.

- `index.html` : la page complète (HTML, CSS et JavaScript intégrés)
- `images/` : photos Unsplash (voir `images/CREDITS.txt`)

Pour le voir en local, ouvrez simplement `index.html` dans un navigateur.
